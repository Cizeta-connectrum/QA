# 製品定義書スキーマ

`products/<id>/definition.md` は以下の章立てで書きます。該当しない章は「該当なし」と書いて残します（章番号を固定して、ボットや教材が参照しやすくするため）。

## フロントマター（YAML）

```yaml
---
product_id: landmarker          # ディレクトリ名と一致
product_name: LANDmarker        # 正式名称
aliases: [Landmark System]      # 別表記・略称
maker: 株式会社アイキャット       # 製造・販売元
category: 歯科インプラント手術支援システム
status: active                  # active / discontinued / planned
version: 1                      # この定義書の版
last_reviewed: 2026-09-10       # 最終レビュー日
owners: [営業企画]               # 定義書の保守担当（役割名。個人名は書かない）
---
```

## 章立て

| # | 章 | 内容 | 主なソース種別 |
|---|---|---|---|
| 1 | 製品概要 | 一言説明、解決する課題、想定ユーザー | カタログ、Web |
| 2 | 構成・ラインナップ | ソフト／サービス／技工物／機器の構成、エディション差 | カタログ、価格表 |
| 3 | 主要機能 | 機能一覧と機能ごとの要点 | 取扱説明書、FAQ |
| 4 | 動作環境・前提条件 | PC 要件、CT 撮影条件、必要データ | 取扱説明書、FAQ |
| 5 | 業務フロー | 導入から納品・手術までの流れ、納期 | カタログ、約款 |
| 6 | 仕様・規格 | 数値仕様、精度、認証番号、届出番号 | 取扱説明書、添付文書 |
| 7 | 価格・契約 | 料金体系、契約期間、更新・解約 | 価格表、約款 |
| 8 | 安全・注意事項 | 警告、禁忌、滅菌・保管条件 | 取扱説明書、添付文書 |
| 9 | サポート | 問い合わせ窓口、受付時間、よくあるトラブル | FAQ、取扱説明書 |
| 10 | 関連製品・競合 | 連携製品、代替手段 | カタログ |
| 11 | 出典 | `sources.yaml` の ID 一覧 | — |

## 出典ラベル

本文中で事実を書くときは、文末に `[S1]` のようにソース ID を付けます。ID は `products/<id>/sources.yaml` で定義します。

## FAQ の形式（`faq.md`）

```markdown
## カテゴリ名

### Q: 質問文（1 文）
A: 回答本文。数値や手順を含める。 [S1]
tags: 導入, ライセンス
```

- `### Q:` で始まる行が質問、次の `A:` で始まる段落が回答。
- `tags:` 行は任意。`scripts/build_qa_dataset.py` がそのまま JSONL に載せます。

## 用語集の形式（`glossary.md`）

```markdown
- **用語**: 説明文。 [S1]
```
