# Dr.Clear 用語集

- **Dr.Clear（クリア博士）**: クリア医療器械技術（常州）有限公司（Bondent Group）の矯正歯科ブランド。シンガポールの Dr.Clear Aligners とは別会社。 [S1][S10]
- **Bondent Group**: Dr.Clear を展開する中国のグループ企業。 [S1]
- **ClearMed（クリアメド）**: Dr.Clear の日本展開における iCAT のカウンターパート。定例会議の相手先。 [S4][S5]
- **C3 フルサイクル矯正**: 乳歯列から永久歯列まで（3〜18 歳）を対象にした小児・青少年向けの段階的矯正コンセプト。筋機能矯正＋マウスピース矯正＋床矯正の 3 in 1。 [S1]
- **C4**: 成人向けマウスピース矯正シリーズ。Basic / Classic / Flex Pro。 [S1]
- **C3-Myo / C3-Moment / C3-Plus / C3-Final**: C3 シリーズの商品名。含まれる装置数とサービス期間（2 年または 5 年）が異なる。 [S1]
- **C4-Basic / C4-Classic / C4-Flex Pro**: C4 シリーズの商品名。非抜歯の単純症例から抜歯・複雑症例まで難易度別。 [S1]
- **クリア OR**: C4-Classic 以上で利用できる機能。C4-Basic は非対応。 [S1] ⚠️ 未確認: 機能の正式名称と内容。
- **ABA 3 層複合シート（ダイヤフラム）**: PETG（A）/ TPU（B）/ PETG（A）の 3 層熱成形シート。総厚 0.030 インチ。 [S1]
- **P+T+P シート**: C4-Flex Pro に使われる二重シェルサンドイッチ構造の超高弾性シート。 [S1]
- **Zendura**: 米国 Bay Materials 社のアライナーシートブランド。Dr.Clear と SPARK が使用。 [S1][S3]
- **Coherz（コハーツ）**: 中国のシートメーカー。Dr.Clear と Angel Aligner が使用。日本で自社シートの認証手続き中。 [S3][S9]
- **NOA 筋機能矯正装置**: Dr.Clear の筋機能トレーナーシリーズ。NOA-F（II 級）、NOA-F3 / NOA-B（III 級）、NOA-U（咬合訓練）、NOA-T（唇訓練）。 [S1]
- **GroForce（グロフォース）**: Growth + Force。小児の顔面・顎・歯データを学習した AI が症状を 5 パターンに分類し、治療プロセスを提案するソリューション。GF2 / GF3 の分類体系。 [S1][S2]
- **BalanForce（バランフォース）**: 抜歯症例向けソリューション。歯の移動、固定源、材料の力の 3 要素を制御。BF1 / BF6。 [S1][S2]
- **パワーリッジ**: BalanForce で前歯部のコントロールに用いるアタッチメント形状。 [S2]
- **ジェットコースター効果**: 抜歯症例で前歯が倒れ込み臼歯が傾く現象。BalanForce が防止対象とする。 [S1][S2]
- **骨格システム（根補助診断システム）**: CBCT と口腔内スキャンを AI で融合し、歯根・歯槽骨形態を復元する機能。 [S1]
- **歯槽弓座標系**: 歯槽骨の解剖学的アーチを基準に歯冠・歯根の移動量を表す座標系。 [S1]
- **WorkBench**: 医師用クラウドポータル。症例送付・発注に使用。 [S3][S4]
- **ClearCheck**: 治療計画の確認ツール。議事録では Career Check とも表記される。 [S3][S4]
- **ステージ**: アライナー 1 枚分の治療段階。1 症例平均 30 ステージ程度、現在は送付上限なし。 [S4]
- **D 系装置（D3〜D11）**: 舌側矯正、ラップアラウンド、顎あて、チークチューブ、拡大装置、三角牽引、下顎前方ガイドなどの補助装置分類。 [S1]
- **MAH（製造販売業者）**: 日本で医療機器を市場に出す責任者。Dr.Clear では iCAT が選任製造販売業者となる想定。 [S9]
- **STED**: 承認申請で求められる技術文書要件。治療支援プログラム（クラス II 承認申請）に適用。 [S6]
- **JMDN コード**: 日本の医療機器一般的名称コード。治療支援プログラム 71044002、咬合誘導装置 70732000、レジン材料 70730000。 [S6]
- **SBOM**: ソフトウェア部品表。IEC 81001-5-1 に基づくサイバーセキュリティ対応で提出が求められる。 [S6]
- **KOL**: キーオピニオンリーダー。日本向け価格体系で KOL 向けとその他の 2 段階を想定。 [S5]
