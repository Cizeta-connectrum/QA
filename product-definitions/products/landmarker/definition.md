# LANDmarker / Landmark System 製品定義書

## 1. 製品概要

**一言で**: CT データと歯列模型（または口腔内スキャン）データを合成し、インプラントの埋入シミュレーションを行い、その結果どおりに手術できるサージカルガイド（Landmark Guide）と補綴物を発注できる、歯科インプラント治療のトータル支援システム。 [S1][S3]

**解決する課題**
- CT 画像だけでは金属アーティファクトや粘膜形状の不足で診断精度が上がらない → 模型データを合成してトップダウン・シミュレーションを可能にする。 [S3]
- シミュレーションと実際のドリリング位置・方向のずれ → 3D プリンタ造形のガイドでスターティングポイントと埋入方向を手術に反映する。 [S2]
- 診断から最終補綴まで工程が分断される → iCAT ラボの CAD ワックスアップ・CAD/CAM 補綴と一気通貫で連携する。 [S3]

**想定ユーザー**: 歯科医院（歯科医師）。契約者は歯科医師免許を持つ個人、または歯科医師が所属する法人に限られる。 [S4]

**位置づけ**: iCAT は 2003 年創業。Landmark System は国内トップシェアのインプラント支援システムと自社カタログで謳っている。 [S3]

| 画像診断用データ | iCAT による模型合成などの「データ作成」 | 個別発注 |
| 歯科技工物 | サージカルガイド（Landmark Guide）、顎模型、CAD/CAM プロビジョナル | 個別発注 |

**ソフトウェアのエディション** [S1]

| 名称 | 役割 | 備考 |

カタログ上のプランとして「スタンダード」「ミニマム」「＋CAD ワックスアップ」という区分がある。 [S5] ⚠️ 未確認: 各プランの内容差はカタログ画像から読み取れていない。

**サージカルガイドの 3 タイプ** [S3]

| タイプ | 内容 | 対応ドリル径 |
|---|---|---|
| シングルガイド | 1 本のドリル径を支援 | φ1.6 / 2.0 / 2.75 / 3.0 mm |
| マルチガイド | 別売サージカルキットのスルーレンチヘッドを付け替え、1 つのガイドで複数径に対応 | φ2.0 / 2.75 / 3.0 mm |
| カスタムガイド | 各メーカーのガイドシステムに対応し、インプラント埋入まで可能 | メーカー依存 |

カスタムガイド対応システム（2020-08 時点）: 京セラ、ケンテック、ジーシー、ブレーンベース、bicon、Biohorizon、camlog、Neoss、Nobel Biocare、Zimmer Biomet（Biomet 3i、LODI、spline）。 [S3]

ガイド形状は「骨上ガイド」と「フラップレスガイド」の 2 種類。 [S2]

## 3. 主要機能

### 3.1 データ取り込み・合成
- DICOM 読込（アキシャル画像）。読込 STEP で金属アーティファクト（不要な歯冠部分）をドラッグ削除できる。合成指標となる部分は残す。 [S1]
- AI 合成（自動）とマニュアル合成（手動）。AI 合成がずれる場合は CT の白黒像と模型の黄色いラインを手動で合わせる。 [S1]
- 残存歯が少ない／無歯顎症例では「CT 撮影用テンプレート（ステント）」にシリコン印象材を塗布して撮影し、造影材の凹凸を合成指標にする。 [S1]

### 3.2 シミュレーション
- インプラント配置、埋入傾斜角の数値表示、配置済みインプラントのコピーによる平行埋入。 [S1]
- 断面表示のカラー分布（オレンジ・黄・緑）で周囲骨質（皮質骨／海綿骨）を相対評価。 [S1]
- パノラミック断面上で点をクリックして下顎管を描出。 [S1]
- 1〜2 歯欠損向けの「簡易ワックスアップ」機能。 [S3]
- サイド固定ピンのシミュレーション（メーカー名「iCAT［サイド固定ピン］」を選択）。 [S2]

### 3.3 インプラントライブラリ
- 各メーカー提供データに基づくリアル形状表示。データ提供のないメーカー（例: ノーベルバイオケア）は円柱表示。 [S1]
- ライブラリにない製品は「数値入力」で直径・長さを指定し、仮の円柱として配置可能。 [S1]
- ライブラリ更新はユーザーズサイトから「LANDmarker 本体」と「インプラントライブラリ」の最新インストーラをダウンロード。 [S1]
- 画面上のインプラント形状は実物と完全一致を保証しない（約款上の免責）。 [S4 第36条]

### 3.4 発注・データ共有
- WEB 受注システム「TeethLink」からガイド・技工物を発注。シミュレーションデータ（.dsb 等）と STL をアップロード。 [S1]
- シミュレーションデータをエクスポートし、LANDmarker（Network 版含む）が入った他院 PC で閲覧可能。 [S1]

## 4. 動作環境・前提条件

### 4.1 PC 要件 [S1]
| 項目 | 内容 |
|---|---|
| OS | Windows 11（64bit のみ）。Mac は BootCamp 等で Windows 環境を構築する必要あり |
| メモリ | 推奨 16GB 以上。不足すると合成時・起動時に極端に遅くなる |
| GPU | 必須ではない。内蔵 GPU（UHD、Iris 等）がないと描画速度に影響 |
| データ保存先 | `C:\iCAT_LM_DIRECT\Data_Base` |
| バックアップ | 上記フォルダを定期的に USB メモリ・外付け HDD・NAS にコピー |

### 4.2 CT 撮影条件 [S1]
- 撮影範囲: 歯列全体を含む φ8cm × 8cm 相当
- ボクセルサイズ: 0.15〜0.2 mm
- 出力形式: DICOM（アキシャル画像のみ）

### 4.3 ネットワーク・ライセンス
- 契約者はハードウェア、インターネット回線、プロバイダ契約を自己負担で整備する。 [S4 第21条]
- ライセンス認証は起動後に表示される MAC アドレスを iCAT へ連絡し、ライセンスキーを発行してもらう方式。 [S1]
- iCAT が配布するバージョンアップを反映しないと利用できなくなる場合がある。 [S4 第24条]

## 5. 業務フロー

### 5.1 全体（iCAT ラボの 3 ステップ） [S3]
1. **事前技工**: 印象・研究用模型、診断用ワックスアップ／CT 撮影用テンプレート、CAD ワックスアップ
2. **データ作成・ガイド作製**: CT 撮影 → 模型合成 → 下顎管抽出 → インプラント仮置 → ガイド作製（＋顎模型、CAD/CAM プロビジョナル）
3. **インプラント技工**: セミカスタムアバットメント、CAD/CAM 補綴、最終補綴

### 5.2 データ作成外注メニュー [S3]
| メニュー | 内容 |
|---|---|
| 外注 1: 模型合成（標準） | 模型合成（欠損部分割付）＋対合顎合成、歯列弓 2 本、下顎症例の下顎管仮抽出、歯冠直下のインプラント仮置 |
| 外注 2: 歯冠・粘膜合成 | 標準に加え、粘膜を示す口腔内模型と診断用ワックス／CT 撮影用テンプレート模型の 2 つを合成 |

### 5.3 納期 [S1]
| 品目 | 納期 |
|---|---|
| データ作成サービス（CAD ワックスアップ） | 通常 5 営業日 |
| サージカルガイド現物 | 発注および模型到着確認から通常 7 営業日 |

### 5.4 サイド固定ガイドの手順 [S2]
1. LANDmarker でサイド固定ピンの埋入シミュレーション
2. ガイド発注時にサイド固定、サイド固定ドリル、サイド固定ピンを発注
3. サイド固定対応ガイドの納品
4. サイド固定ドリルでピンホールを形成（骨内 9 mm）
5. サイド固定ピンでガイドを固定

### 5.5 検収 [S4 第11条]
- 納品後直ちに歯科医師が検収する。納品日から 3 営業日以内に不合格通知がなければ適合とみなす。
- 所有権は代金支払い時に移転。

## 8. 安全・注意事項

### 8.1 滅菌・消毒 [S2]
ガイド・ドリル・キットはいずれも未滅菌で納品。超音波洗浄後に滅菌または消毒する。

| 方法 | ガイド | キット | ドリル | 備考 |
|---|---|---|---|---|
| 薬液除菌（アクトリル等） | ○ | △ | △ | 10 分浸漬、精製水で水洗 |
| EOG 滅菌 | × | ○ | ○ | 48.7 ℃超でガイド変形 |
| オートクレーブ（134 ℃ 10 分） | × | ○ | ○ | ガイド熱変形。乾燥工程 140 ℃超はケース変形の恐れ |
| ホルマリンガス消毒 | △ | ○ | ○ | 機種により 48.7 ℃超（ホルホープ可、ホルステリ不可） |

- ガイドは荷重でも変形する。上に物を載せない。
- アルコール系消毒液はガイド表面が曇る。浸漬 30 分以内。
- ストッパーはドリル径ごとに内径が異なるため、外さずに滅菌する。

### 8.2 手術時の注意 [S2]
- 使用前にスルーレンチヘッドの変形を点検（パイプ部上面と板部が約 6 mm 間隔で「ほぼ平行」）。
- ドリリング前に必ずガイドの適合を確認。適合しない場合は使用中止。
- ガイドは咬合面に対し垂直に押さえる（唇側からの力はアンダーカットでずれる）。
- 固定ドリルは回転させずに挿入し、600〜800 rpm で穿孔。骨が硬い場合は 1600〜1800 rpm。
- 推奨回転数: 下顎 400〜800 rpm、上顎 200〜600 rpm。最終ドリルは下顎 200〜400、上顎 100〜300 rpm 以下。
- 固定ネジ・スルーレンチヘッド単体使用時は誤飲対策として糸を通す。
- ドリルが斜めの状態で回し続けると摩擦熱でガイドチューブが外れることがある。
- サイド固定ドリルは外部注水式で折れやすい。ポンピングしながら慎重に。抜去はピンを埋入方向にまっすぐ引き抜く。
- CT 撮影から手術までの期間が長いと顎骨変化で適合しなくなる。抜歯直後は特に注意。

### 8.3 保管・記録 [S2][S4 第17条]
- 手術後もガイド・CT データ記録媒体・研究用模型を最低 3 カ月保管する（約款上の義務）。
- 本システムは診療録の代替にならない。診療録は別途作成・保管する。 [S4 第36条]

### 8.4 責任分界 [S4]
- 診療行為・診断内容の責任は契約者（医療機関）が負う。
- iCAT の損害賠償は契約者が支払った利用対価総額を上限とし、逸失利益等は対象外。
- 患者情報は契約履行と匿名化した統計利用に限って使用される。

### 9.2 よくあるトラブルと対処 [S1]
| 症状 | 原因 | 対処 |
|---|---|---|
| 起動しない／「vcruntime140_1.dll が見つからない」 | Windows Update 失敗等で必要ファイル欠損 | Microsoft 公式から C++ 再頒布可能パッケージをインストール |
| DICOM 読込中に強制終了 | 患者像のないファイル（CT 値 -1000 のみ）混入、スライス間隔不均一 | 不要ファイルを除外して再読込 |
| 患者一覧が遅い | Data_Base 内のデータ数過多（1,000 件超など） | 過去データを別フォルダに移動 |
| AI 合成がずれる | 金属アーティファクト多い、撮影範囲が狭い | マニュアル合成で微調整 |
| ライブラリに最新インプラントがない | バージョン未更新 | 本体とライブラリの最新インストーラで更新 |

### 9.3 PC 入れ替え手順 [S1]
1. ユーザーズサイトから最新インストーラをダウンロードしてインストール
2. 起動後に表示される MAC アドレスを iCAT へ連絡し、新ライセンスキーを受領
3. 旧 PC の `C:\iCAT_LM_DIRECT\Data_Base` 内の患者データを新 PC の同フォルダにコピー
